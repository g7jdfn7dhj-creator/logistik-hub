# Logistik-Hub v5 — PWA

Устанавливаемое веб-приложение **склада**: учёт запаса **в деталях (шт.)**, 3D-схема склада (240 ячеек стеллажей), показатели склада, отчёт (печать/CSV). Производственная часть (цеха H1–H9, станки, персонал, симуляция «что-если», фуры/заказы/KPI поставок) в v5 удалена.

**В программе нет встроенных данных и значений по умолчанию.** При первом запуске склад пуст, параметры «не заданы», показатели «—». Запас меняется только:

- ручным вводом (вкладка «Ввод»: номер детали, название, место, количество, класс размера S/M/L);
- импортом файлов CSV/JSON (вкладка «Данные»);
- **Arbeitzeit — строго в одну сторону, только чтение** (Arbeitzeit → Logistik-Hub): CSV склада (Lager), чтение `localStorage['timetracking-lager-parts']` на том же origin, необязательный адрес GET. Logistik-Hub никогда ничего не записывает в Arbeitzeit и ничего туда не отправляет.

## Детали, классы размера, места

- Деталь = номер детали (уникален), название, место, количество (шт., необязательно), класс размера **S / M / L** (необязательно).
- Класс задаётся в форме (иконки маленькой/средней/большой детали) или колонкой файла `size` / `Größe` / `Размер` (`S/M/L`, `small/medium/large`, `klein/mittel/groß`, `маленькая/средняя/большая`). Без класса деталь показывается «без класса» — класс не придумывается.
- Место `R1-05-2` = ряд 1–4, секция 1–20, ярус 1–3. Другие места сохраняются, но в 3D не показываются.
- Паллеты/коробки показываются только при поступлении; на складе всё хранится и считается в деталях.

## Импорт

- CSV склада Arbeitzeit: UTF-8 с BOM, `;`, CRLF, заголовок `Номер детали;Место;Название` / `Teilenummer;Lagerort;Bezeichnung` / `Part number;Location;Name`; необязательно колонки «Количество» и «Размер».
- Свои CSV/JSON: поля `num`, `loc`, `name`, `qty`, `size` (и RU/DE синонимы); JSON — массив или `{"parts":[…]}`.
- Перед применением — предпросмотр (новые / изменятся / без изменений / нет в файле) и выбор: **«Только добавить/обновить»** (по умолчанию, ничего не удаляется) или **«Полная инвентаризация»** (детали, которых нет в файле, удаляются).

## 3D-анимация изменений (только изображение)

- Добавление детали или увеличение количества (ввод, импорт, Arbeitzeit) → к рампе приёмки приезжает фура, паллеты выгружаются, погрузчики ставят их в целевые ячейки; там затем видна деталь.
- Удаление или уменьшение (вручную или полной инвентаризацией) → логисты выносят детали из ячейки через заднюю дверь в зону **«Производство»** за складом.
- Данные меняются и сохраняются сразу; анимация ничего не меняет и не блокирует. Большие импорты группируются, очередь ускоряется. Случайных «декоративных» поставок нет. Анимацию можно выключить (меню ☰ или кнопка в панели, клавиша `A`).
- Качество 3D: «Авто» (на телефонах — пониженное разрешение без теней; при медленной отрисовке переключается само), «Высокое», «Низкое».

## Переход с v4

- Ключи хранения прежние (`lhub.r4.data`, `lhub.r4.params`). При первом запуске v5 данные v4 переносятся автоматически:
  - детали (номер, место, название) сохраняются; количество и класс — если были в данных;
  - записи запаса стеллажей превращаются в детали (количество паллет не пересчитывается в штуки — «не задано»);
  - фуры, заказы, производство, запас зоны производства и параметры смен/персонала/симуляции удаляются;
  - исходная копия данных v4 сохраняется в `lhub.r4.v4backup` и входит в экспорт JSON.

## Развёртывание

1. Нужен **HTTPS** (service worker и установка работают только по HTTPS; исключение — `localhost`).
2. Загрузите **содержимое** этой папки (не саму папку) в любую директорию сайта, например `https://workbridgepersonal.de/logistik-hub/`. Все пути относительные — работает из любой подпапки.
3. Откройте адрес в Chrome/Edge (кнопка «⤓ Установить приложение» в шапке или значок установки в адресной строке) или в Safari на iPhone/iPad («Поделиться» → «На экран „Домой“»).

### Прямая синхронизация с Arbeitzeit

Браузер показывает `localStorage` только страницам **одного origin** (протокол + домен + порт). Если разместить Logistik-Hub на том же домене, что и Arbeitzeit — `https://workbridgepersonal.de/logistik-hub/` рядом с `https://workbridgepersonal.de/arbeitszeit/`, — кнопка «Синхронизировать с Arbeitzeit» читает реестр деталей напрямую (только чтение). На другом домене (например, GitHub Pages) используйте в Arbeitzeit «Склад → Экспорт CSV» и импорт этого файла в Logistik-Hub.

## Интерфейс

- **Ручной ввод:** кнопка **«+ Деталь»** в шапке (клавиша `E`) открывает вкладку «Ввод»; щелчок по ячейке стеллажа в 3D показывает её детали и «+ Деталь в эту ячейку».
  - Вкладка «Склад»: список деталей с иконками, поиск, фильтр по классу, правка и удаление.
  - Пустые таблицы и подсказки ведут сразу к нужной форме.
- **Подсказки закрываются (×):** «Нет данных», тревоги на сцене, строка «Склад».
  - В меню «☰» есть «Скрыть подсказки» (сохраняется) и «Вернуть закрытые подсказки».
- **Телефон:**
  - Компактная шапка: название, «+», меню.
  - Строка KPI прокручивается и сворачивается.
  - Сцена занимает около 44 % высоты; на вкладках с формами она уменьшается. Кнопка ⤢ раскрывает сцену на весь экран.
  - Вкладки — одна прокручиваемая строка с иконками; кнопки не меньше 44 px; учтены вырезы экрана.
  - В горизонтальной ориентации сцена и панель стоят рядом.
- **ПК/ноутбук:**
  - Ширина панели меняется перетаскиванием разделителя или ←/→ на нём.
  - Двойной щелчок или `P` скрывает панель; в меню есть «Широкая панель (дашборд)».
  - `F` — весь экран, `V` — вид, `Esc` — назад.
- Настройки интерфейса хранятся в ключе `lhub.r4.ui`; «Очистить всё» удаляет и его.

## Хранение данных — только на этом устройстве

- Все введённые и загруженные данные хранятся только в браузере на этом устройстве. На сервер ничего не отправляется.
- **Основное хранилище — localStorage**, ключи: `lhub.r4.data` (формат v5), `lhub.r4.params`, `lhub.r4.azUrl`, `lhub.r4.ui`, `lhub.r4.rev`, `lhub.r4.migrated`, `lhub.r4.v4backup`, `lhub.lang`.
- **Вторая копия — IndexedDB** (`lhub-local`, файл `store.js`).
  - Обновляется при каждом изменении и дополнительно при сворачивании или закрытии страницы.
  - Если localStorage очищен (например, iOS удалил данные) или устарел, данные при запуске автоматически восстанавливаются из второй копии.
- **Защита от автоочистки:** при первом вводе (или при запуске, если данные уже есть) приложение запрашивает `navigator.storage.persist()`.
  - Статус показан на вкладке «Данные» и в меню ☰: «Данные хранятся только на этом устройстве · защищены от автоочистки: да/нет» и занятый объём.
- **Память заполнена:** появляется сообщение. Если localStorage переполнен, изменения сохраняются во второй копии.
- «Очистить всё» удаляет обе копии, только ключи `lhub.r4.*`.
- Резервная копия JSON (экспорт/импорт) работает как раньше. Это единственный способ перенести данные на другое устройство: синхронизации между устройствами нет.
- **Обновление приложения меняет только кэш оболочки** (`lhub-pwa-*`). localStorage и IndexedDB не затрагиваются.
  - Новая версия ищется при запуске, при возврате в приложение и раз в час.

### Сетевые обращения (аудит)

- Программа ничего не отправляет: нет POST и запросов с телом, нет `sendBeacon`, WebSocket и аналитики.
- Сеть используется только для чтения:
  - файлы самой программы (тот же адрес);
  - проверка новой версии (`sw.js`);
  - необязательный адрес GET для данных Arbeitzeit — только если вы его указали. Запрос идёт с `credentials:'omit'`, без тела, и не кэшируется.

## Офлайн и обновления

- Оболочка (index.html, манифест, иконки, иконки деталей, текстуры 3D, three.js, шрифты) кэшируется при первом открытии (cache-first, версионированный кэш `lhub-pwa-vN`, старые версии удаляются при активации). После этого приложение запускается без сети.
- Адрес GET для Arbeitzeit и любые другие запросы данных идут **только в сеть** и никогда не кэшируются.
- При выходе новой версии внизу появляется «Доступна новая версия — обновить?». Для выпуска новой версии измените `VERSION` в `sw.js` (и `app-version` в `index.html`). При установке файлы загружаются в обход HTTP-кэша браузера (`cache:'reload'`).

## Локальная проверка

```bash
python3 -m http.server 8080
# или: npx http-server -p 8080 -c-1
```

Откройте `http://localhost:8080/` (именно `localhost` — на нём SW работает без HTTPS).
