# Logistik-Hub — PWA

Устанавливаемое веб-приложение для управления логистикой и производством предприятия: режим «Факт» (реальное время), симуляция «что-если», KPI, диаграмма Ганта рамп, портфель заказов, сменный отчёт (печать/CSV), 3D-схема склада и цехов.

**В программе нет встроенных данных и значений по умолчанию.** При первом запуске все параметры «не заданы», показатели «—», 3D-сцена пуста. Данные появляются только из:

- ручного ввода (вкладка «Ввод»);
- импорта файлов CSV/JSON (вкладка «Данные»);
- **Arbeitzeit — строго в одну сторону, только чтение** (Arbeitzeit → Logistik-Hub): импорт CSV склада (Lager), чтение `localStorage['timetracking-lager-parts']` на том же origin, необязательный адрес GET. Logistik-Hub никогда ничего не записывает в Arbeitzeit и ничего туда не отправляет.

Все параметры и данные хранятся локально в браузере (ключи `lhub.r4.*` — данные из Logistik-Hub R4 на том же адресе подхватываются автоматически). Есть экспорт/импорт всего в JSON и «Очистить всё».

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | приложение (Logistik-Hub R4) |
| `manifest.json` | манифест PWA |
| `sw.js` | service worker: офлайн-кэш оболочки |
| `pwa.js` | регистрация SW, уведомление об обновлении, кнопка «Установить приложение» |
| `vendor/three.min.js` | three.js r128 (локальная копия, без CDN) |
| `fonts/` | шрифты IBM Plex Mono, Saira Condensed, Roboto Condensed (woff2, латиница + кириллица) |
| `icons/` | иконки 192/512, maskable 512, apple-touch-icon, favicon |
| `.nojekyll` | для GitHub Pages |

## Развёртывание

1. Нужен **HTTPS** (service worker и установка работают только по HTTPS; исключение — `localhost`).
2. Загрузите **содержимое** этой папки (не саму папку) в любую директорию сайта, например `https://workbridgepersonal.de/logistik-hub/`. Все пути относительные — работает из любой подпапки.
3. Откройте адрес в Chrome/Edge (кнопка «⤓ Установить приложение» в шапке или значок установки в адресной строке) или в Safari на iPhone/iPad («Поделиться» → «На экран „Домой“»).

### Прямая синхронизация с Arbeitzeit

Браузер показывает `localStorage` только страницам **одного origin** (протокол + домен + порт). Если разместить Logistik-Hub на том же домене, что и Arbeitzeit — `https://workbridgepersonal.de/logistik-hub/` рядом с `https://workbridgepersonal.de/arbeitszeit/`, — кнопка «Синхронизировать с Arbeitzeit» читает реестр деталей напрямую (только чтение). На другом домене (например, GitHub Pages) используйте в Arbeitzeit «Склад → Экспорт CSV» и импорт этого файла в Logistik-Hub.

## Офлайн и обновления

- Оболочка (index.html, манифест, иконки, three.js, шрифты) кэшируется при первом открытии (cache-first, версионированный кэш `lhub-pwa-vN`, старые версии удаляются при активации). После этого приложение запускается без сети.
- Адрес GET для Arbeitzeit и любые другие запросы данных идут **только в сеть** и никогда не кэшируются.
- При выходе новой версии внизу появляется «Доступна новая версия — обновить?». Для выпуска новой версии измените `VERSION` в `sw.js`.

## Локальная проверка

```bash
cd pwa
python3 -m http.server 8080
# или: npx http-server -p 8080 -c-1
```

Откройте `http://localhost:8080/` (именно `localhost` — на нём SW работает без HTTPS).
